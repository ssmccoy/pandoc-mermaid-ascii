===============================================================================
Pandoc mermaid-to-text filter
===============================================================================

This tiny little widget is a pandoc filter which when installed (with ``make
install`` from the root of this repository will filter ``mermaid``
class-labeled code blocks using ``mermaid-ascii(1)``, discovered via your
``$PATH``.

It is intended for use with Alexander Grooff's mermaid-ascii_ project.

.. _mermaid-ascii: https://github.com/AlexanderGrooff/mermaid-ascii
